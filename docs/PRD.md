# 사이트 설계도(PRD) — 소문

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.
지금 사이트: https://sosomun.com/ (내 사업. 문의가 잘 들어오게 새로 만든다)

## 1. 한 줄 정의
인터넷·TV, 정수기, 가전렌탈, 생활 서비스를 20대부터 중장년·시니어까지, 일반 가정과 사업자 모두에게 차근차근 전화로 설명해 드리고 상담을 이어 주는 곳.
(소문은 렌탈 계약 당사자가 아닌 통신판매중개자이며, 상품·계약 책임은 렌탈사에 있다 — 지금 사이트에 적힌 그대로)

## 2. 손님
- 누가: 20대, 중장년, 시니어 — 일반 가정과 사업자(개업·매장 준비) 모두
  - 공통점: 복잡한 요금·약정을 쉽게 설명 듣고 싶은 분
  - 가장 배려할 손님: 시니어 (시니어가 쉽게 쓰면 모두가 쉽게 쓴다)
- 어디서 알고 오나: 자녀·지인 소개, 카카오톡, 네이버 검색, 전단지·명함 QR
  → 휴대폰으로 들어온다고 보고 만든다. 글자는 크게, 버튼은 크고 하나로.
  → 첫 화면 아래에 "가정용 / 사업자용" 두 갈래 길을 보여 주어 각자 자기 이야기를 찾게 한다.

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 한 달에 얼마인지 (월 납입료·총 납입금액)
2. 어렵지 않은지 (전화 한 통이면 되는지, 차근차근 설명해 주는지)
3. 속지 않을지 (위약금·해지 조건, 숨은 비용)
4. 설치·관리는 어떻게 하는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 사업자 정보 공개 (사업자등록·주소·통신판매중개자 안내)
- 금액을 숨기지 않음 (총 납입금액을 보여 주고, 확인 안 된 것은 "확인 중"·"상담 시 안내"로 표시)
- 계약 전 확인 안내 (위약금·해지 안내를 미리 보여 줌)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 전화로 설명 듣기
- 누르면: 문의 폼 (이름·연락처를 남기면 소문이 전화를 걸어 드림)

## 6. 페이지 구성 (위에서 아래로)
**1장. 홈**
1. 첫 화면 — 한 문장 + "전화로 설명 듣기" 버튼
2. 궁금한 것 네 가지에 대한 짧은 답 (얼마인지 / 어렵지 않은지 / 속지 않을지 / 설치·관리)
3. 가정용 / 사업자용 두 갈래 — 가정용: 인터넷·TV, 정수기, 가전렌탈 / 사업자용: 매장 인터넷, 업소용 가전, 매장패키지, 정책자금 (금액은 "상담 시 안내", 등록된 예시 금액만 표시)
4. 믿을 수 있는 이유 — 사업자 정보 · 금액 공개 원칙 · 계약 전 확인
5. 후기 자리 (비워 둠)
6. 문의 폼

**2장. 상품·서비스 안내**
- 가전렌탈 8개 대분류 (주방, 생활, 환경·건강, 가구, 디지털·사무, 업소용, 통신·모빌리티, 패키지)
- 생활 서비스 9개 (이사, 청소, 부동산, 인테리어, 쇼핑몰, 보험, 매장패키지, 정책자금, 광고·홍보)
- 조건 계산기 · 조합별 금액표 (지금 사이트에 등록된 자료만 사용)
- 각 칸마다 "전화로 설명 듣기" 버튼

**3장. 계약 전 확인**
- 계약 전 확인, 자주 묻는 질문, 해지 안내
- 사업자 정보, 개인정보처리방침, 이용약관
- 파트너 모집 (짧은 안내 + 파트너 상담 접수)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 관심 상품 (인터넷·TV / 정수기 / 가전렌탈 / 생활 서비스 / 사업자·매장 준비 중 고르기)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (지금 사이트에 적힌 그대로 — 만들기 전에 사장님 확인 필요)
- 가격: 대부분 "상담 시 안내". 등록된 예시 — 코웨이 정수기 자가관리 36개월 조합 총 납입금액 1,724,400원 / 방문 2개월 84개월 조합 3,855,600원
- 시간: (미정 — 상담·전화 가능 시간)
- 위치: 경상남도 양산시 동면 금오16길 4, 1층 104호 (사업자 주소)
- 연락 방법: 문의 폼(전화 회신), 카카오톡 채널, 이메일, 전화 010-6380-7778 (지금 사이트의 사업자 정보에 적힌 번호. 사장님이 상담 번호로 쓰라고 정함)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제 (온라인 결제 없이 상담으로만 연결)

## 10. 첫 화면 한 문장 후보
1. 인터넷·정수기·가전렌탈, 전화 한 통으로 차근차근 설명해 드립니다.
2. 복잡한 요금, 숨기지 않고 쉽게 알려 드립니다.
3. 계약 전에 꼭 아셔야 할 것부터 먼저 말씀드립니다.

## 11. 다음에 할 것
- 실제 고객 후기 모으기 → 후기 자리에 넣기
- 상담 시간 확정해서 넣기
- 회원가입·로그인 (필요해지면. 그때 개인정보 처리방침 보강)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함 (20대도 세련되게 느끼되 시니어 배려: 큰 글자, 높은 대비, 큰 버튼)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
